    📖 API Documentation

    Generate a QR code that automatically verifies payment via Gmail.

    GET /v2/fam/API_KEY&qr=AMOUNT
    /v2/fam/YOUR_KEY&qr=100
    • Amount: any positive number (e.g. 100, 250.50)
    • QR expires after 15 minutes
    • Polling endpoint: /api/check-payment/<order_id>
    • Verified only when FamPay email arrives in Gmail
